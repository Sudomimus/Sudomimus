# Sudomimus maintainability audit, round two

## Summary

1 confirmed defect. The sample covered the TypeScript release planner and target selection, plus the dependency closure of the C# Native console example.

## Scope and method

Reviewed the current local worktree and compared the cited behavior with its owner contracts and earlier reports.

## Findings

### AUDIT-001 — Native console sample ships an unused Connect SDK dependency

- **Class and rating** — Defect, P3, high confidence.
- **Evidence and contract** — The [examples index](../../examples/README.md#L9) describes Native authentication. The [console project](../../examples/csharp/console/Sudomimus.Examples.Console.csproj#L17) recommends and references Connect. Both [Program.cs](../../examples/csharp/console/Program.cs#L25) and its [linked source](../../examples/csharp/SteamTermsText.cs#L2) use Native types. A [comment](../../examples/csharp/console/Program.cs#L210) claims both namespaces are imported.
- **Behavior and impact** — Readers following the installation example add an extra SDK. The existing Debug dependency manifest lists Connect as a direct dependency and includes its assembly in the console application’s runtime assets.
- **Repair and verification** — Remove the Connect reference and installation example, then correct the type-qualification comment. Run the existing CI Release build for the console project, check its dependency manifest and retain the Native login example.

## Verification record

Verified project references, all compiled example source files, the examples index, the existing Debug dependency manifest and the [CI build command](../../.github/workflows/ci-csharp.yml#L37). The audit did not rebuild or publish the example.
