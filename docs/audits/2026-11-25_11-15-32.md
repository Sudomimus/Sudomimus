## Findings

### AUDIT-001 — Native console sample ships an unused Connect SDK dependency

- **Status** — Resolved.
- **Class and rating** — Defect, P3, high confidence.
- **Original evidence and impact** — The console example in the [examples index](../../examples/README.md#L9) demonstrates Native authentication. Its project previously referenced and recommended Connect, so the extra assembly appeared in the runtime output.
- **Repair** — Removed both Connect references from the [console project](../../examples/csharp/console/Sudomimus.Examples.Console.csproj#L13) and corrected the [example title](../../examples/csharp/console/README.md#L1) and [type-qualification comment](../../examples/csharp/console/Program.cs#L210). The console still uses Native, Session, and Token.

## Verification record

The audit inspected project references and the existing Debug dependency manifest. Remediation ran the [CI Release build](../../.github/workflows/ci-csharp.yml#L37) with .NET SDK 10.0.203 and cached .NET 8 reference packs in an isolated output directory. The build succeeded with zero warnings or errors. The fresh dependency manifest lists Native, Session, and Token as the only direct dependencies. The output contains no Connect assembly.
