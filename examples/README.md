# Examples

| Example | Flow | Notes |
| --- | --- | --- |
| [React + Node](typescript/react) | Connect callback and server-side session | Browser receives an HttpOnly cookie; backend holds credentials. |
| [Node CLI](typescript/node) | Connect status poll and Device authorization | Run `pnpm start` or `pnpm device`. |
| [Python CLI](python) | Connect status poll | Interactive login and session rotation. |
| [Django](python/django) | Connect callback and Django session | Local web app with CSRF-protected forms. |
| [C# console](csharp/console) | Native Steam ticket or access key | Includes claim-gated errands. |
| [Godot](csharp/godot) | Native Steam ticket or access key | Requires GodotSteam. |

Each directory's README lists its setup and the application rules it needs.
